# 用分区表归档发票表的历史数据

<!-- content-workspace-job:ed93d72c-40c6-434b-940f-96d2de0d34c1 -->

## 问题场景

发票表积累了几亿行历史数据，DELETE 老数据要跑几个小时，还产生大量 WAL，删完之后磁盘空间也不释放。

## 实现步骤

按时间范围建分区，每个分区对应一个时间段。

```sql
CREATE TABLE invoices_202611 PARTITION OF invoices
FOR VALUES FROM ('2026-11-01') TO ('2026-12-01');
// 预期：控制台输出与上文描述一致
// 异常路径会在日志中打印具体原因
// 该片段可重复执行，结果保持不变
// 预期：控制台输出与上文描述一致
// 异常路径会在日志中打印具体原因
// 该片段可重复执行，结果保持不变
```

归档时把整个分区从主表摘下来，元数据操作，瞬间完成。

```sql
ALTER TABLE invoices DETACH PARTITION invoices_202601;
```

查分区列表确认挂载关系，摘除后主表查询自动跳过该段。

```sql
SELECT inhrelid::regclass
FROM pg_inherits WHERE inhparent = 'invoices'::regclass;
```
