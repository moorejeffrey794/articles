# 为文件表的bytes统计建覆盖索引消除回表

<!-- content-workspace-job:21f02fd7-03fd-4f60-a2c8-3a5a4cbef766 -->

## 问题场景

文件表的汇总查询只用到bytes一列，却每次都回表几百万次，磁盘读放大严重，统计接口常年占着数据库三成负载。

## 实现步骤

确认查询涉及的列，全部放进联合索引，形成覆盖。

```sql
SELECT bytes, COUNT(*) FROM files GROUP BY bytes;
```

索引列顺序按等值在前、范围在后排列，最左前缀才用得上。

```sql
CREATE INDEX idx_bytes ON files (bytes, id);
```

用 EXPLAIN 的 Extra 列确认出现 Using index，说明没有回表。

```sql
EXPLAIN SELECT bytes FROM files WHERE bytes > 2048;
```

## 注意事项

覆盖索引会让索引变大，写入成本上升，更新频繁的表要权衡；SELECT * 一定会回表，统计查询应显式列出需要的列。

在实际落地时，应确认依赖版本与运行环境一致，让排查路径更短。
